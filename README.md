# Fivemmedicalcenter.github.io
Le FMMC (FiveM Medical Center) est un outil destiné à faciliter le travail des EMS sur FiveM RP. Il permet d’identifier les traitements selon les symptômes des patients, de consulter la grille tarifaire des soins et consultations, et de calculer automatiquement le montant total des prestations médicales.
